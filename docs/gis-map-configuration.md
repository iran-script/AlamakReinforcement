# تنظیمات نقشه GIS

## نقشه پایه

مدیر مجاز از مسیر `/settings/gis-map` آدرس سرویس Tile Map را ثبت می‌کند. آدرس باید HTTP/HTTPS یا یک مسیر داخلی سامانه باشد و پارامترهای `{z}`، `{x}` و `{y}` را داشته باشد. مقدار هر سازمان مستقل است؛ مقدار سازمانی بر تنظیم عمومی اولویت دارد و در نبود آن، `GIS_BASE_TILE_URL` یا مقدار پیش‌فرض داخلی استفاده می‌شود.

مجوزها با منبع `gis_settings` و عملیات `view` و `configure` در `DataAccessPolicy` کنترل می‌شوند. ایجاد و تغییر تنظیم از طریق `AuditLogger` ثبت می‌شود.

## لایه‌های عملیاتی

مدیر مجاز می‌تواند در صفحه تنظیمات با دکمه «افزودن لایه»، یک لایه WMS یا Vector Tile سازمانی بسازد. این لایه‌ها در `gis_map_layers` نگهداری می‌شوند، از سازمان دیگر قابل مشاهده یا حذف نیستند و ایجاد/حذف آن‌ها در Audit Log ثبت می‌شود.

لایه‌های سیستمی نیز می‌توانند در `config/gis.php` تعریف شوند. تعریف سازمانی با کلید یکسان، لایه عمومی یا سیستمی را برای همان سازمان override می‌کند. انواع `vector_tile` و `wms` پشتیبانی می‌شوند. نمونه Vector Tile:

```php
'assets' => [
    'title' => 'دارایی‌ها',
    'type' => 'vector_tile',
    'endpoint' => '/tiles/assets/{z}/{x}/{y}.pbf',
    'visible' => true,
    'min_zoom' => 8,
    'max_zoom' => 22,
],
```

کلید باید یکتا باشد و endpoint باید یک منبع MVT معتبر فراهم کند. مسیرهای داخلی با base path نصب XAMPP ساخته می‌شوند. پس از تغییر فایل تنظیمات در محیطی که config cache فعال است، cache تنظیمات باید دوباره ساخته شود.

نمونه WMS:

```php
'service_zones' => [
    'title' => 'محدوده‌های خدماتی',
    'type' => 'wms',
    'endpoint' => 'https://maps.example.test/geoserver/wms',
    'layers' => 'workspace:service_zones',
    'format' => 'image/png',
    'transparent' => true,
    'version' => '1.3.0',
    'styles' => '',
    'server_type' => 'geoserver',
    'visible' => true,
    'min_zoom' => 0,
    'max_zoom' => 22,
],
```

مقادیر مجاز `format` شامل PNG، JPEG و WebP و نسخه‌های مجاز WMS شامل `1.1.1` و `1.3.0` است. پارامترهای درخواست از فهرست مجاز ساخته می‌شوند و قطعه کد یا پارامتر اجرایی از فایل تنظیمات پذیرفته نمی‌شود. سرویس خارجی باید از مرورگر کاربران و شبکه محل استقرار برنامه قابل دسترسی باشد.

این قابلیت جدول‌ها، مسیرها و رفتار تصاویر و فرم‌های قدیمی عملیات را تغییر نمی‌دهد.
